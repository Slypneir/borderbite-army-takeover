В этом замере Brotli легче и даже быстрее, но проверено только локально на настольной машине: на слабом телефоне распаковка в JS может занять заметно больше. Для Playables оставлен вариант без сжатия: 9,65 МиБ укладывается в цель, а риск отказа на сертификации не нужен. Вернуть Brotli — строка `Compression` в `Assets/Scripts/Editor/PlatformBuildProfile.cs`.

## Что проверено

- Поиск `CrazyGames`, `crazygames`, `Yandex`, `yandex`, `YaGames`, `ysdk`, `sdk.js` внутри `.wasm`, `.framework.js`, `.loader.js`, `index.html` и распакованных архивов `.data`: ничего, кроме исключения ниже. Единственный адрес площадки в сборке — тег SDK в `index.html`; остальные найденные адреса — ссылки на документацию и лицензии внутри строк Unity и шрифта, запросов по ним нет.
- Исключение: `slurp|yandex` в `Playables.loader.js` — список поисковых ботов в загрузчике самого Unity, не код площадки и не адрес.
- Поддельный `ytgame` (`stub_youtube.js`), порядок вызовов: `getLanguage`, `isAudioEnabled`, `firstFrameReady`, `loadData`, `gameReady`; выключение и включение звука; пауза останавливает главный цикл, возобновление запускает; `saveData` после `loadData`. Язык `ru-RU` дал русские тексты.
- Вертикаль и альбом: `Docs/Verification/setup/`. Карта не обрезана, тексты привязаны к верхнему и нижнему краям.
- EditMode: 64 из 64. Хеш боя на каждом тике одинаков при 60, 144, 165 Гц и неровных кадрах. В Play Mode с `targetFrameRate` 60, 144, 165 (измеренные 50, 143, 160 кадров) хеш на тике 300 один: `0AD90E17CF96A08E`.
- Сборки CrazyGames и Яндекса (7,12 и 7,11 МиБ по сети, Brotli + Fallback): собираются, запускаются, 0 ошибок консоли, слов других площадок нет. CrazyGames — с настоящим SDK в локальном режиме; Яндекс — с поддельным `YaGames` (`stub_yandex.js`), поле при окне 600×1600 ограничено 600×1200.

- Настоящая среда YouTube, Яндекса и CrazyGames, настоящий показ рекламы, SDK Test Suite, портал разработчика.
- Телефоны, Chromebook 4 ГБ, слабый Android. Время — с программным WebGL и локальным сервером: только для сравнения сборок.
- Пик кучи JS не измерялся; задан предел памяти 512 МБ.
- Сборка пустая: игрового контента нет, вес будет расти.
