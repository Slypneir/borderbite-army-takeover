## Что проверено

- Поиск `CrazyGames`, `crazygames`, `Yandex`, `yandex`, `YaGames`, `ysdk`, `sdk.js` в распакованных `.wasm`, `.framework.js`, `.data` с архивами внутри, в `.loader.js` и `index.html`: ничего, кроме исключения ниже. Этот поиск делает `build_report.mjs`, его надо запускать после сборки: быстрая проверка внутри `PlatformBuild` сжатые файлы не читает. Единственный адрес площадки в сборке — тег SDK в `index.html`; остальные найденные адреса — ссылки на документацию и лицензии внутри строк Unity и шрифта, запросов по ним нет.
- Исключение: `slurp|yandex` в `Playables.loader.js` — список поисковых ботов в загрузчике самого Unity, не код площадки и не адрес.
- Поддельный `ytgame` (`stub_youtube.js`), порядок вызовов: `getLanguage`, `isAudioEnabled`, `firstFrameReady`, `loadData`, `gameReady`; выключение и включение звука; пауза останавливает главный цикл, возобновление запускает; `saveData` после `loadData`. Язык `ru-RU` дал русские тексты.
- Вертикаль и альбом: `Docs/Verification/setup/`. Карта не обрезана, тексты привязаны к верхнему и нижнему краям.
- EditMode: 64 из 64. Хеш боя на каждом тике одинаков при 60, 144, 165 Гц и неровных кадрах. В Play Mode с `targetFrameRate` 60, 144, 165 (измеренные 50, 143, 160 кадров) хеш на тике 300 один: `0AD90E17CF96A08E`.
- Сборки CrazyGames и Яндекса (7,12 и 7,11 МиБ по сети): собираются, запускаются, 0 ошибок консоли, слов других площадок нет. CrazyGames — с настоящим SDK в локальном режиме; Яндекс — с поддельным `YaGames` (`stub_yandex.js`), поле при окне 600×1600 ограничено 600×1200.
